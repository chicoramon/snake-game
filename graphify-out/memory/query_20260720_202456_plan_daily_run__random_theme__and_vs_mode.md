# Q: Plan Daily Run, Random Theme, and Vs mode

## Answer

Plan Daily Run as a UTC server-issued seeded Sprint 60 challenge with a versioned deterministic ruleset, three ranked attempts, a global daily leaderboard, streaks, nearby rivals, and replay validation. Add a one-shot Random Theme button that excludes the current theme and persists its selection, while Daily uses one shared fixed theme. Build Vs in phases: share-link asynchronous same-seed duels, replay-based ghost/progress races, then Supabase Realtime rooms with synchronized countdowns and server-verified results.
